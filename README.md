# LitBrief — Образовательный портал кратких содержаний (КР №2 / КР №3)

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Проект представляет собой образовательный портал с краткими содержаниями и анализом произведений художественной литературы (аналог Briefly.ru и Polka.academy), разработанный с использованием Bootstrap.

## Практическая работа 9
Выполнена главная страница на Bootstrap-сетке.
Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок литературных эпох и преимуществ;
- сетка популярных пересказов недели;
- подвал страницы.

## Используемые технологии
- HTML;
- Bootstrap;
- CSS;
- Git;
- GitHub.

## Структура проекта
- `index.html` — главная страница;
- `css/custom.css` — пользовательские стили;
- `README.md` — описание проекта;
- `.gitignore` — исключённые файлы.
