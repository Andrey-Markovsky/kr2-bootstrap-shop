# LitBrief — Литературно-аналитический портал кратких содержаний (КР №2 / КР №3)

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Проект представляет собой многостраничный литературно-аналитический портал с поглавными краткими содержаниями, системой ключевых образов и проверенным цитатным фондом произведений классической художественной литературы, разработанный с использованием фреймворка Bootstrap 5.

## Используемые технологии
- HTML5;
- Bootstrap 5 (CDN);
- CSS3 (пользовательские стили и ключевые кадры анимаций `@keyframes`);
- JavaScript (ES6+, `localStorage`, работа с DOM и буфером обмена);
- Git и GitHub Pages.

## Структура проекта
- `index.html` — главная страница (центральный разбор недели, навигация по литературным эпохам, популярные издания, форма предложения нового разбора);
- `catalog.html` — база из 9 книг с иллюстрациями книжных форзацев, калькулятором времени чтения, индивидуальными модальными карточками и встроенным полным поглавным разбором каждого произведения;
- `profile.html` — личный кабинет читателя с настройками профиля и разделом «Избранное»;
- `order.html` — страница «О проекте» (методология филологического анализа, структура библиотечного фонда и ответы на частые вопросы);
- `contacts.html` — контактная информация редакции, часы работы и ссылки на официальные каналы связи;
- `css/custom.css` — пользовательские стили, фиксация каркаса страницы, правила доступности (`:focus-visible`) и CSS-анимации;
- `js/main.js` — логика переключения и отрисовки 9 книг, живого поиска по сайту, расчёта времени чтения, сохранения избранных книг в `localStorage` и копирования цитат;
- `README.md` — описание проекта;
- `.gitignore` — список исключённых системных файлов.

## Практическая работа 9
Выполнена главная страница на 12-колоночной сетке Bootstrap (`container`, `row`, `col-*`, `g-*`).
Реализовано:
- подключение Bootstrap 5 через CDN и собственного файла `css/custom.css`;
- закреплённая шапка страницы и единый подвал;
- главный блок с книжным форзацем издания недели;
- раздел литературных направлений и эпох;
- сетка популярных изданий фонда.

## Практическая работа 10
Тема: «Страница на Bootstrap: компоненты».
Выполнено:
- добавлена единая адаптивная навигация `navbar` на все страницы;
- разработана база из 9 классических произведений (`catalog.html`) с карточками `card` и метками `badge`;
- добавлены индивидуальные всплывающие окна `modal` для каждой из 9 книг;
- реализован полный разбор произведений с таблицей образов (`table-responsive`), поглавным пересказом на базе `accordion` и разделом цитат;
- добавлена форма предложения нового разбора (`form-control`, `form-select`, `input-group`, `form-check`) с клиентской валидацией.

## Практическая работа 11 (Финальная проверка и самостоятельные доработки)
Выполнены самостоятельные доработки сверх базового задания:
- **База из 9 полностью проработанных произведений** с векторными иллюстрациями книжных форзацев и экслибрисом;
- **Интерактивный калькулятор времени чтения** внутри базы книг с поддержкой как ручного ввода скорости чтения, так и быстрых пресетов, сопровождаемый плавной анимацией шкал сравнения;
- **Живой поиск по сайту** в шапке всех страниц (по названию книги, фамилии автора и персонажам);
- **Система «Избранное» и Личный кабинет (`profile.html`)** с сохранением выбранных произведений и настроек пользователя в `localStorage`;
- **Тематические CSS-анимации:** 3D-открывание обложки книги внутри книжной рамки при переходе к разбору, плавная анимация кнопки «Избранное» с вылетом сердечек и анимированные индикаторы расчёта времени чтения;
- **Цитатник** с функцией мгновенного копирования цитат в буфер обмена;
- настроены правила доступности (`:focus-visible`) и адаптивности.
